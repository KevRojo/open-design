### 🌟 Codename: *值得信赖的运行结果*

🧭 **29 个 PR · 12 位贡献者** — **0.24.0 让你看到的状态就是真实发生的情况。** 过去，一个正常结束的任务可能因为无关的标记被错标为阻断；一次 Agent 主动拒答的回合可能显示成红色的"失败"卡片，而不是它真正的回复；预览有时明明页面正常却渲染成空白。这些都不会再骗你了。🚀

## 🔥 亮点

- 🧭 **运行状态终于对得上实际发生的事。** 正常结束的任务不再因为无关标记被误判为阻断；Agent 主动拒答的回合现在会显示它真正的回复，而不是一张红色"失败"卡片；长时间运行也不会再在负载下丢事件或截断事件。 (#8350, #8322, #8170) 感谢 @itscheems、@lefarcen。

- 🖼️ **预览不再说谎。** 快照桥接的一个 bug 会让部分实际能正常工作的页面渲染成空白预览，现在预览会如实展示页面本来的样子。 (#7125) 感谢 @huynextlevel。

- 🔁 **恢复会带着凭证回来。** 崩溃、分叉对话或读取过期数据之后重新打开聊天，Agent 不会跟丢：恢复出来的产出不再被误标成手动编辑，阻断判定能扛过重新加载，只做规划的回合在澄清后依然保留原意，正在进行的策略也会留在发起它的任务里。 (#8007, #8008, #8172, #8195, #8067, #8029) 感谢 @app/open-design-crew、@lefarcen。

- 🏠 **首页体验持续变好。** 在 0.23.0 改版的基础上，首页新建工作默认走 Prototype（可以直接在输入框里切换类型），项目分栏在交接过程中保持稳定，钱包为空时也会提前给出答案而不是卡在半路。 (#8208, #8278, #8229, #8240) 感谢 @Siri-Ray、@app/open-design-crew。

- 💬 **聊天区更实诚了。** 对话继续往下走之后，未回答的问题会自动收起；运行失败的文案对齐了产品定稿；解析失败的卡片会直接隐藏，而不是渲染出一堆乱码。 (#8158, #8140, #8258, #8264) 感谢 @app/open-design-crew、@lefarcen。

- 🚀 **更新不会卡在一半。** 更新程序现在会原子化地把新版本交接给正在运行的应用，中断的更新不会再把你留在一个装了一半的版本上。 (#8348) 感谢 @PerishCode。

- 🤖 **模型更多，Agent 更稳。** Novita AI 模型目录进一步扩充，Copilot CLI 的检测逻辑改为优先使用直连二进制，自动化 CLI 也不会再在读到子命令之前就抛错。 (#6327, #7974, #7612, #8066) 感谢 @jax-novita、@tony-box、@johnkattenhorn、@app/open-design-crew。

- 🌐 **法语翻译补齐。** Library、Memory 和设计体系流程的文案已经完整翻译。 (#7756, #7906) 感谢 @davezfr。

> 📥 **下载：** 发布资源将会出现在 [Open Design 0.24.0](https://github.com/nexu-io/open-design/releases/tag/open-design-v0.24.0)。

## 🔁 变更

- 切换 profile 时工作区订阅现在能正确重置，运行快照也会正确统计基于 manifest 的产物，而不是遗漏它们。 (#8020, #7586) 感谢 @AmyShang-alt、@arccat-114。
- 结构异常的 daemon payload 现在会等待启动器就绪后再处理，而不是提前失败；封面渲染的超时也做了分类，晚到的输出会被清理而不是一直挂着。 (#7520, #8061) 感谢 @lorenzozanee、@app/open-design-crew。
